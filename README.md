# FGO 羁绊礼装配装

帮你算出这一队该带哪些羁绊礼装，也能从你拥有的从者里补满空位，让羁绊拿得最多。数据为日服。

**直接使用：** https://xtshen777.github.io/fgo-bond/

> 非官方粉丝工具，计算结果仅供参考。

## 能做什么

- **算礼装：** 选好 6 个从者，自动挑出最赚的羁绊礼装组合，并显示每人能拿多少点。
- **补空位：** 放好主刷、打手和拐，一键从你的从者里补满队伍，同时配好礼装。
- **记录持有：** 分别标记你有哪些从者和礼装，只用你有的来算。
- **考虑实际规则：** 支持 COST 上限、助战、冠位从者、绊 15 加成、茶壶和前后排。

## 怎么用

1. 在“我的从者”里，点头像标记“已有”或“满绊”。
2. 在“我的礼装”里，取消勾选你没有的礼装。
3. 回到“配队”，加入想带的从者，给主要想刷的人点“主刷”。
4. 填好基础羁绊、御主等级、茶壶和关卡类型。
5. 点“填满空位并配礼装”，或者直接看算好的礼装结果。

结果不满意时，可以拖动头像和礼装调整，也可以手动换礼装。网站填入的人点“留下”后就会保留。

## 关卡类型

| 选项 | 可编入的职阶 | 冠位多 1 个礼装位 |
|---|---|---|
| 日常本 | 不限 | 否 |
| 冠位战：七骑 | 只有对应职阶 | 是 |
| 冠位战：EX1 | 裁、仇、月、盾 | 是，同类别自己的冠位只算 1 名 |
| 冠位战：EX2 | 分、外、伪、兽 | 是，同类别自己的冠位只算 1 名 |

## 羁绊怎么算

```text
单人羁绊 = (⌊⌊基础羁绊 × 位置加成⌋ × (1 + 礼装加成 + 绊 15 加成)⌋ + 固定点数) × 茶壶倍率
```

`⌊⌋` 表示去掉小数。

- **位置加成：** 前排 +20%；助战在前排时，全队再 +4%。
- **绊 15：** 每名自己的绊 15 从者给全队 +25%，放在助战位无效。
- **茶壶：** 星见 ×2，月见 ×3。

这个公式已用一次实际结算核对，1 名绊 15 时 5 名从者的点数全部一致。2 名及以上绊 15 的叠加、英灵肖像固定点数的计算位置还没有实测。

## 你的数据存在哪

从者和礼装记录都只存在当前浏览器里，不会上传。换设备或清理浏览器数据前，请在“我的从者”页底部导出从者记录；礼装记录目前没有导出功能，需要重新勾选。

## 更新数据

需要 macOS（图片缩放用系统自带的 `sips`）和 Python 3。

```bash
rm -f .cache/*.json
python3 tools/build.py
```

脚本会重新生成 `index.html` 和 `img/`。图片都放在仓库里，访客不会访问 Atlas Academy，只有运行这个脚本时才会下载新增的数据和图片。

- 页面逻辑和样式在 `tools/template.html`，不要直接改 `index.html`。
- 如果提示缺中文名，把新从者补到 `tools/build.py` 的 `ZH_NAMES`。
- 新羁绊礼装加到 `tools/build.py` 的 `EQUIP_IDS`。
